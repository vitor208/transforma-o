O Desafio da Colisão de Hash

Uma Função Hash transforma dados de qualquer tamanho em um valor numérico fixo. Mas o que acontece se duas entradas totalmente diferentes gerarem exatamente o mesmo resultado?

Seu Objetivo:

Encontrar duas palavras diferentes (com no mínimo 2 letras cada) que produzam o mesmo valor de Hash utilizando a função calcula_hash.

ASCII Sum Validação em Tempo Real Sem Distinção Visual
calcula_hash.js 
function calcula_hash(palavra) {
  let hash = 0;
  
  // Percorre cada caractere da palavra
  for (let i = 0; i < palavra.length; i++) {
    // Soma o valor ASCII do caractere
    hash += palavra.charCodeAt(i);
  }
  
  return hash;
}
Esta função calcula o Hash acumulando os códigos inteiros do padrão ASCII / Unicode de cada letra.

Dicas & Auxílio

Segredo da Matemática:

Como a nossa função de hash apenas soma os códigos ASCII sem se importar com a posição da letra, a adição é comutativa (A + B = B + A).

💡 Dica prática: Qualquer palavra que seja um anagrama (mesmas letras em ordem diferente) de outra palavra gerará a mesma soma de hash!

Teoria Avançada

Por que a nossa função falha e como funcionam hashes reais?

Compreenda a falha de projeto da soma ASCII simples e o efeito avalanche das funções criptográficas modernas.

1

Comutatividade na Soma Simples

A função calcula_hash que construímos na aula utiliza a operação matemática da Adição Simples. A adição possui a propriedade comutativa:

ASCII('A') + ASCII('M') + ASCII('O') + ASCII('R')
=
ASCII('R') + ASCII('O') + ASCII('M') + ASCII('A') = 303

Como a ordem dos fatores não altera a soma, qualquer permuta de letras gera uma Colisão de Hash trivial.

2

Hashes Criptográficos Reais (SHA-256)

Algoritmos modernos de mercado como o SHA-256 utilizam operações bitwise complexas (deslocamentos de bits, rotações, XOR) que dependem estritamente da posição de cada caractere.

Isso produz o chamado Efeito Avalanche: alterar apenas a posição de uma única letra muda completamente todo o hash final, tornando colisões extremamente improváveis.
